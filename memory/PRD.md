# NutriFlow AI — Product Requirements

## Product
Premium AI Nutrition Platform — mobile-first Expo React Native app powered by GPT-5.2 (nutrition/scan/blood-test), GPT Image 1 (meal photos), Stripe subscriptions, and JWT + Emergent Google Auth.

## MVP Scope (delivered)
1. **Auth** — Email/password (JWT, PBKDF2 hashing) and Emergent-managed Google login (session-token exchange).
2. **Conversational onboarding** — chat-style multi-step questionnaire collecting age, gender, height, weight, goal, activity, cuisines, allergies, avoid, meals/day; determines targets.
3. **AI Body Analysis** — deterministic Mifflin–St Jeor + activity multiplier; returns BMI/kcal/macros/water/scores (metabolism, nutrition, hydration, health) + target weight & finish date.
4. **AI Meal Planner** — 7/14/30-day plans generated by GPT-5.2 with title, description, macros, cooking time, difficulty, cost, ingredients, steps. On-demand GPT Image 1 photo per meal.
5. **Smart Meal Replacement** — GPT-5.2 swaps a meal keeping macros within ±15%.
6. **Shopping List** — aggregated ingredients auto-grouped (vegetables/fruit/meat/fish/dairy/grains/frozen/drinks/spices/other) with checkboxes and estimated total cost.
7. **Photo Food Scanner** — camera/upload, GPT-5.2 vision → food name, macros, sugar, health score, portion, healthier alternative.
8. **Blood Test Analysis** — PDF (pypdf) or image upload; GPT-5.2 explains each marker (normal/low/high), suggests foods, habits, nutrients, with medical disclaimer.
9. **AI Nutritionist Chat** — GPT-5.2 conversational chat with user context (profile-aware), persistent history, suggested prompts.
10. **Habits** — daily water tracker with quick-add (250/500/750 ml), streak.
11. **Profile & Subscription** — Stripe Checkout (Pro $9.99/mo, Family $19.99/mo), language switcher (EN/RU), theme switcher (Light/Dark/System), logout.
12. **Recipes (backend)** — GPT-5.2 recipe generator + fridge mode (available at /api/recipes/generate).

## Stack
- Frontend: Expo SDK 54, React Native 0.81, Expo Router, react-native-svg, expo-blur, expo-camera, expo-image-picker, expo-document-picker, @gorhom/bottom-sheet.
- Backend: FastAPI + Motor (Mongo), emergentintegrations (LLM + image), Stripe.
- LLM: openai/gpt-5.2, openai/gpt-image-1 via EMERGENT_LLM_KEY.
- Auth: JWT (PBKDF2), Emergent Google Auth (session token).
- I18n: EN + RU built-in.

## Endpoints
- Auth: `/api/auth/{register,login,google/session,me,logout}`
- Profile: GET/PUT `/api/profile`, GET `/api/analysis/body`
- Meals: POST `/api/meals/generate`, GET `/api/meals/plans`, GET `/api/meals/plan/{plan_id}`, POST `/api/meals/{meal_id}/image`, POST `/api/meals/{meal_id}/replace`
- Shopping list: GET `/api/meals/plan/{plan_id}/shopping-list`
- Scan: POST `/api/scan/food`, GET `/api/scan/history`
- Blood test: POST `/api/blood-test/analyze` (multipart), GET `/api/blood-test/history`
- Chat: POST `/api/chat/send`, GET `/api/chat/history`, DELETE `/api/chat/session/{id}`
- Recipes: POST `/api/recipes/generate`, GET `/api/recipes`
- Habits: POST `/api/habits/log`, GET `/api/habits`
- Stripe: POST `/api/stripe/checkout`, GET `/api/stripe/session/{id}`, GET `/api/subscription`
